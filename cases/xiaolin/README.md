# 贯穿案例：小林的财务改造

> 小林是虚构人物，他身上集中了新手最常见的问题。每一章我们都用学到的东西帮他解决一个问题，到第 22 章，他会有一套完整的个人理财系统。

## 小林的初始档案（第 1 章时）

| 项目 | 情况 |
|---|---|
| 年龄 | 28 岁，单身，在二线城市做程序员 |
| 收入 | 税后月薪约 12,000 元，年终奖不固定 |
| 每月支出 | 约 10,000 元，具体花在哪他自己也说不清 |
| 现金 | 银行卡活期约 30,000 元 |
| 负债 | 信用卡分期 20,000 元（买手机和电脑），每月还 1,800 元 |
| 投资 | 去年跟同事买了一只「明星基金」投入 15,000 元，目前账面亏损约 30%，不敢看 |
| 保险 | 只有公司缴纳的社保，没有任何商业保险 |
| 目标 | 「想五年后攒够首付」，但不知道首付要多少、每月该存多少 |

## 他的四个典型问题（全课反复引用）

1. **钱不知道去哪了**：收入不低，月底却总是不剩钱。（第 2、3 章解决）
2. **没有安全垫**：一旦失业或生病，只能刷信用卡。（第 4、5 章解决）
3. **投资靠听说**：买过什么、为什么买、什么时候卖，全凭感觉。（第 6-14 章解决）
4. **目标是口号**：「攒首付」没有金额、没有期限、没有计划。（第 21、22 章解决）

## 进度记录

| 章 | 小林完成了什么 |
|---|---|
| 01 | 意识到自己的钱只有「花」和「乱投」两个去处；用复利计算器算出：如果每月稳定存 2,000 元，长期下来差别有多大 |
| 02 | 做出第一份资产负债表和现金流量表：账面净资产 48,500，可动用仅 17,500；现金对账发现每月约 3,000 元未记录支出，真实月结余为 -1,000 元 |
| 03 | 导出 10 月流水，找到消失的 3,000 元（旅行 1,200、人情 1,000、餐饮和购物低估 800）；建立年度大额池每月 800，发薪日自动转出储蓄 2,300，新预算结余比率约 19%，分期还清后升至约 34% |
| 04 | 必要支出 7,600/月，现有 3 万可撑 3.9 个月；分期真实年化约 13%，但提前还款仍收剩余手续费，决定按期还、不再分期；应急金目标 6 个月 4.6 万，约 6.8 个月存满；信用卡改全额自动还款 |
| 05 | 配置保障：百万医疗险 + 综合意外险 + 定期重疾（保额约 40-50 万）+ 所在城市惠民保；暂不买寿险和返还型产品；总保费控制在年收入 5%-10%（7,200-14,400），计入年度大额池。第一阶段「守住钱」完成 |
| 06 | 给每笔钱贴期限标签：应急金和年度大额池为现金类，首付储蓄约 5 年为债主股辅；被套基金需涨约 43% 回本，留待第 10 章分析；承受力自测结果为「10 万变 7 万会睡不着」，股票类比例宜低 |
| 07 | 应急金分两层：银行活期约 9,200（约 1 个月必要支出）+ 货币基金约 36,800；不用定期（利率与货基相近且提前支取利息归零）；年度大额池单独放一只货币基金；暂不用国债逆回购 |
| 08 | 首付储蓄以短债基金和中短久期纯债基金为主，久期不超过剩余持有年限；暂不配二级债基、可转债基金和单只企业债；距买房 1-2 年起逐步转入货币基金和存款 |
| 09 | 通过券商官方 App 开户，风险测评为稳健型；月末用 1,000 元试了一次 1 天期国债逆回购；收藏宽基指数只看不买；不碰个股；意识到过去一年在基金 App 上操作二十多次、追涨杀跌 |
| 10 | 拆解被套基金：偏股混合主动基金，重仓单一热门行业，历史最大回撤超 40%，买在规模暴涨的季度；按「今天是现金还买不买」判断，决定卖出并把 10,500 元转入宽基指数基金（第 11 章），一周内完成，不择时 |
